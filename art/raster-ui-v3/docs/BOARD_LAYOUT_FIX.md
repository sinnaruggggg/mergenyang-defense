# 전투 보드 비율 수정

전체 화면 1080×1920 (9:16), 좌측 상단 원점.

기존 보드 칸 원본은 403×390 PNG였으나 178×105로 강제 변형되어 가로로 늘어났습니다. 수정본은 원본 비율을 유지하는 contain 배치이며, 칸 영역은 144×139입니다. 프레임·발바닥 무늬·아이템을 가로/세로 다른 배율로 늘리지 않습니다.

- 5열×7행, 35칸
- 보드 시작: (164,674)
- 칸 영역: 144×139
- 칸 간격을 포함한 이동량: 가로152, 세로146
- 칸 좌표: x=164+열×152, y=674+행×146 (열/행은 0부터)
- 보드 칸 전체 영역: 752×1015, 마지막 칸 하단1689
- 아이템 영역: 각 칸 내부 (17,10), 110×110, 원본 비율 유지
- 레벨 글자: 각 칸 내부 (76,112), 60×27
- 보드 외곽 패널: (142,651), 796×1061

전투 캐릭터와 공격 효과의 높이를 조정하고 보급 레일을 위로 이동했습니다. 보드 선택 효과는 아이템/레벨 글자 아래에 배치합니다. 튜토리얼 안내도 보드를 덮지 않도록 이동했습니다.

대상: battle, battle-coop, battle-boss, battle-pvp, tutorial. 상세 배치와 클릭 영역은 각 layouts JSON과 coordinates.csv에 기록됩니다. 그림은 기존 이미지 원화를 사용하고 PNG 배치만 변경했습니다.
