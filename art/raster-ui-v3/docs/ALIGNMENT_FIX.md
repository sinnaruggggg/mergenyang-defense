# 중앙 정렬 수정 · 2026-09-17

82개 화면의 버튼 303개를 조사했습니다. 303개 버튼 묶음에 대해, 실제로 보이는 PNG 픽셀과 버튼의 밝은 면을 기준으로 정렬했습니다. 나무 받침과 투명 여백은 버튼 면의 중앙 계산에서 제외했습니다.

 버튼 문구와 아이콘을 묶어서 좌우 중앙에 맞추고, 제목 띠·게이지·하단 탭의 문구와 아이콘도 보정했습니다. 버튼 묶음의 최종 가로/세로 오차는 각각 최대 0.5px입니다. 이는 픽셀 기준 검사 결과이며 그림의 비대칭에 따른 시각적 느낌까지 자동 판정하는 수치는 아닙니다.

`previews/alignment-before-after.png`: 위는 기존, 아래는 수정본입니다.
`previews/aligned-buttons.png`: 여러 메뉴의 수정된 버튼을 모아 확인하는 이미지입니다.
`docs/alignment-audit.json`: 검사 기준, 이동 전후 좌표, 잔여 오차를 기록했습니다.

좌표표와 메뉴 미리보기, 화면별 PNG 및 JSON을 갱신했습니다. 이후 재생성은 `node tools/rebuild.cjs`를 사용하세요. 버튼을 누르면 해당 상태의 그림 면 이동량에 맞춰 문구와 아이콘도 함께 이동합니다.

아이콘/버튼 원화는 재그리거나 도형으로 대체하지 않았습니다. 이번 수정은 기존 PNG의 배치 좌표를 조정한 작업입니다.
