# 머지냥 공격 모션 V4

기획서에 이름이 명시된 고양이 6종, 일반 적 10종, 챕터 보스 5종, 월드보스 4종: 총 25종의 공격 준비/타격 2프레임입니다. 중간 보스는 기획서대로 챕터 보스의 축소형을 재사용합니다. 이름과 외형이 정해지지 않은 향후 시즌 몬스터/스킨은 포함하지 않습니다.

- `index.html`: 재생/정지/프레임 이동/겹쳐 보기 검사기
- `characters/<id>/attack-0.png`: 준비
- `characters/<id>/attack-1.png`: 타격
- `characters/<id>/attack-sheet.png`: 좌→우 2프레임
- `manifest.json`: 프레임, 원본 영역, 배율, 좌표, 방향, 재생 시간
- `sources/`: 투명 원화
- `production.json`: built-in imagegen 최종 프롬프트와 출처
- `validation.json`: 투명도, 경계, 공통 배율 검사

## 엔진 배치

모든 프레임은 512×512, 시트는 1024×512입니다. 상단 원점 기준 피벗은 (256,472), 정규화하면 (0.5,0.921875)입니다. 하단 원점에서는 (256,40), 정규화 (0.5,0.078125)입니다. 월드 기준점 (X,Y)에 배치할 때 상단 원점 UI 위치는 (X−256×S, Y−472×S), 크기는 (512×S,512×S)로 두 프레임 모두 동일하게 설정합니다. 개별 프레임의 보이는 외곽에 맞춰 auto-fit하거나 크기를 다시 맞추지 마세요.

공통 권장 시간은 준비 220ms, 타격 140ms이며, 타격 판정은 frame 1 진입 시 발생시킵니다. 게임 밸런스상의 공격 주기는 별도 cooldown으로 관리하세요. 원거리 투사체/피해 판정은 별도 엔티티입니다. 고양이는 오른쪽, 적은 왼쪽 공격입니다. 캐릭터 간 월드 크기는 게임에서 따로 지정하고 같은 캐릭터의 두 프레임에는 같은 S를 적용하세요.

## 제작 및 정확성

캐릭터 그림과 공격 자세는 built-in imagegen으로 그렸습니다. 코드는 기존 PNG의 분리, 동일 배율 리사이즈, 투명 캔버스 배치와 재생에만 사용했습니다. 코드로 캐릭터나 아이콘을 그리지 않았습니다.

원화의 실제 투명 간격을 찾아 두 포즈를 분리하며, 같은 캐릭터에 공통 배율을 적용합니다. 바닥 지지 부위의 기준점을 정렬했습니다. 양쪽 그림은 새로 그린 포즈이므로 얼굴·의상·몸 윤곽의 미세한 차이가 있으며, '모양이 절대 바뀌지 않는 픽셀 동일성'을 보장하는 리깅 결과는 아닙니다. 고정 캔버스/배율 검사를 외형의 완전 동일성 검사로 해석하면 안 됩니다.

기존 V3 메뉴 패키지와 단순 이동 모션은 보존했습니다. 실제 게임 실행 코드에 자동 통합하지 않은 별도 공격 에셋 패키지입니다.
