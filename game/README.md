# 머지냥 디펜스 · 플레이 가능한 웹 빌드

`art/` 폴더의 PNG 에셋(V3 UI, V4 공격 모션)을 그대로 사용하는 HTML5 캔버스 게임입니다. 기획서(`art/source/game-design.md`)의 코어 루프를 구현했습니다.

## 실행

- 가장 간단한 방법: `game/index.html`을 브라우저로 엽니다. 파일로 직접 열면 브라우저 보안 정책 때문에 Noto Sans KR 대신 시스템 글꼴(맑은 고딕)로 표시될 수 있습니다.
- 로컬 서버 사용(권장, 전용 폰트까지 적용):

```bash
python -m http.server 8765 --directory "D:/머지냥디펜스"
```

그다음 `http://localhost:8765/game/index.html`에 접속합니다. 모바일 브라우저에서도 세로 화면으로 플레이할 수 있습니다.

## 구현 범위

| 영역 | 내용 |
| --- | --- |
| 흐름 | 타이틀 → 로비(대장간) → 모드 → 챕터·스테이지 → 출전 준비 → 전투 → 결과 |
| 머지 | 5×7 보드, 4라인×8단계, 연쇄 합성, 5개 합성(상위 2개), 보물상자, 첫 8단계 연출·도감 |
| 보급 | 레일 자동 배달(역할별 대상), 고양이 위에 놓으면 지정 배달, 특수 라인 즉시 광역기 |
| 전투 | 고양이 5종(탱커 어그로, 근접 돌진, 화살·화염구·성광 투사체), 몬스터 10종, 쓰러짐/부활 |
| 보스 | 챕터 보스 5종 + 중간 보스, 70%·30% 패턴, "!" 경고 중 보급하면 긴급 보급 성공 → 반격 |
| 챕터 규칙 | 독(2장), 레일 감속(3장), 보드 빙결(4장), 흡입·보호막(5장) |
| 모드 | 개인 디펜스 100스테이지, 무한의 탑, 월드보스(주간 순환 4종, 90초, 하루 3회) |
| 연출 | 피버 타임, 콤보, 화면 흔들림, 히트스톱, 슬로모션, 섬광, 번개, 데미지 숫자, 골드 흡수 |
| 성장 | 고양이 레벨업, 대장간 4종·머지냥이 3종 강화, 방치 보상, 에너지, 별 3개 평가 |
| 기타 | 상점(일일 상자, 보석 교환), 로컬 랭킹, 설정, 도움말, WebAudio 효과음·BGM, 자동 저장 |

멀티 디펜스·대전·실결제·온라인 랭킹은 서버(Nakama)와 Google Play 연동이 필요해 잠금 표시만 해 두었습니다.

## 구조

```
game/
  index.html
  js/core.js     캔버스, 입력, 9-slice, 즉시모드 버튼
  js/audio.js    효과음·BGM 합성
  js/data.js     수치 테이블, 에셋 목록, 저장
  js/fx.js       파티클·카메라 연출
  js/battle.js   전투 씬
  js/scenes.js   메뉴 씬, 팝업
  js/main.js     씬 전환, 메인 루프
  dev/testkit.js 개발용 자동 플레이·시뮬레이션 (게임에 포함되지 않음)
```

밸런스 수치는 `js/data.js`의 `stageScale`, `ITEM_VALUE`, `catMul`, 각 몬스터·보스 테이블에서 조정합니다. 개발 중 확인은 브라우저 콘솔에서 `await fetch('dev/testkit.js').then(r => r.text()).then(eval)` 후 `sim({mode:'stage', ch:4, st:19}, 20)`처럼 실행합니다.
