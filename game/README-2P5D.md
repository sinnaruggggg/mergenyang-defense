# 2.5D 대장간·걷기·아이템 확장

`index.html`의 로비는 기존 성과 아치 배경을 유지합니다. `js/workshop-room.js`에서 같은 배율로 배경을 위로 360px 옮겨 대장간 영역(0~1010)에 실제 바닥이 충분히 들어오도록 합니다. 새 방 배경으로 교체하지 않았습니다.

화로·작업대·통·모루·상자는 투명 여백을 정리한 `*-grounded.png`를 사용합니다. 각 물건의 폭만 지정하고 높이는 원본 비율에서 계산합니다. 실제 이미지 밑면을 지정된 바닥 y에 맞추고 접지 그림자 PNG를 먼저 표시합니다. 물건의 바닥 면적과 고양이 발 위치로 앞뒤 순서를 계산합니다. 등불은 잘못된 공중 배치를 피하기 위해 이번 장면에서 제외했습니다.

출전 편성에 있는 고양이만 이동합니다. 이동 영역 x=90~990, y=560~956 안에서 물건 바닥 면적을 피해 30px 경로 격자를 탐색합니다. 다른 고양이와 너무 가까워지면 잠시 멈추고 목적지를 다시 고릅니다. `dev/grounded-validation.json`에 실제 재생 및 120초 이동 시뮬레이션 결과가 있고, `dev/workshop-behind.png`와 `dev/workshop-front.png`로 작업대 뒤/앞 가림을 비교할 수 있습니다.

걷기 에셋은 `assets/walk/`에 25종×2프레임입니다. 고정 512×512 캔버스와 pivot(256,472)을 사용합니다. 몸 크기·윤곽을 유지하기 위해 frame 1은 frame 0의 같은 픽셀을 (0,-3)으로 이동한 것입니다. `dev/walk-motion-review.html`에서 반복 재생하고, `validation.json`은 두 프레임의 정확한 이동 일치를 기록합니다.

아이템은 4라인×16단계=64종입니다. 9~16단계의 신규 32종 PNG는 `assets/items-extra/`에 있고, 기존 1~8단계와 함께 `js/data.js`의 `ITEM_FILES`, `ITEM_NAMES`, `MAX_TIER`에서 관리됩니다.
